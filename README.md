# PurpJob

Инфраструктура профессионального доверия: Profile → Evidence → PROF / Trust → Match.

**Это вторая версия, и она начинается с чистого листа.** Основа — вайрфреймы «исправленный путь
кандидата» (98 экранов, контуры A–L), обновлённый мастер-документ и дизайн-система. Строится по
одному блоку: блок → показ → правки → следующий.

## Первая версия

Сохранена целиком меткой **`v1`**: модули 1–16 по FRD, мастер-документ 10.17, 575 тестов, CI.
Убрана из основной ветки не потому, что сломана, а потому, что вайрфреймы описывают другое
устройство продукта — отдельные экраны вместо одной страницы, проекты с режимом раскрытия NDA,
интервью по опыту вместо отдельных вопросов, кабинет кандидата, приватность и удаление профиля.
Ядро прежнее, и правила из первой версии остаются в силе: отсутствие данных не снижает Trust, PROF
относится к роли, Match существует только в паре с вакансией.

Как открыть первую версию:

| Зачем | Как |
|---|---|
| посмотреть файлы | на GitHub в переключателе веток выбрать метку `v1` |
| запустить | на рабочем компьютере — `start.cmd` в папке `PurpJob v1` рядом с этой |
| взять конкретный файл | `git show v1:путь/к/файлу` |

Первая версия работает со своей базой `purpjob` и при старте сверяет её схему с кодом. Второй
версии нужна **отдельная** база: если перестроить `purpjob` под новый код, первая перестанет
запускаться с вашими данными.

## Документы

- [`docs/history/`](docs/history/) — версии мастер-документа, 10.16 и 10.17. Не редактируются.

Порядок источников истины для второй версии ещё не зафиксирован. Вайрфреймы местами расходятся с
мастер-документом — например, в 10.17 Trust Score это число, а во вайрфреймах числа нет, пока
методика не утверждена. Что побеждает при расхождении, решается до первой строчки кода.
